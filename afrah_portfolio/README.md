# Fathima Afrah — Portfolio

A responsive static portfolio website built with HTML, CSS and a small amount of JavaScript.

## Run locally
Open `index.html` in a browser, or run:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Deploy
Upload the contents of this folder to the root of the `portfolio` GitHub repository. Keep `assets/resume.pdf` in place so the Resume links work on the deployed site.

## Before publishing
- Add your SmartVein-ID device photo/video and replace the abstract project artwork if desired.
- Add the deployed ParcelPilot Streamlit URL to its project card (replace the “Live demo link to be added” text).
- Add repository URLs for projects where you want a Code link.
- Verify LinkedIn URL and contact details before publishing.

The portfolio content is based on the supplied one-page resume. No live demo URL or SmartVein-ID media was supplied, so those are intentionally not fabricated.
